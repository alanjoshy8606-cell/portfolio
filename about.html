04 HEART DISEASE PREDICTION & ML SYSTEM
MACHINE LEARNING / HEALTHCARE WEB APP View GitHub Repo

HEART / 01 — Heart Disease Prediction System

HEART / 01 is an end-to-end machine learning web application designed for heart disease risk assessment and clinical health analytics. Powered by an optimized Random Forest classifier (300 estimators, balanced class weights) achieving 93.30% accuracy and 98.36% ROC-AUC, the system evaluates patient clinical attributes to predict cardiovascular disease risk. Built with a robust Flask backend, input validation, Chart.js visual analytics dashboard, and persistent SQLite prediction history.

Key Features:
  • Supervised ML classification pipeline using Random Forest (93.30% accuracy, 98.36% ROC-AUC).
  • Comparative model benchmarking against Logistic Regression with stratified cross-validation.
  • Interactive clinical prediction form with real-time input validation for patient features.
  • Dynamic healthcare dashboard powered by Chart.js displaying risk distributions and insights.
  • Production ML pipeline integrating Scikit-Learn OneHotEncoder and ColumnTransformer.
  • Prediction history logging and local database management using Python's SQLite3.
  • Responsive healthcare UI styled with an elegant deep burgundy and soft rose visual theme.
Technologies & Algorithms:
Python Flask Scikit-learn Random Forest Pandas Joblib SQLite3 Chart.js HTML5 CSS3 JavaScript

05 USED CAR PRICE PREDICTION & VALUATION
MACHINE LEARNING / REGRESSION & WEB APPLICATION View GitHub Repo

AUTOVAL — Used Car Price Prediction System

AUTOVAL is an end-to-end machine learning regression system and web application designed to estimate fair used vehicle resale prices based on detailed car specifications. The system trains and benchmarks 11 regression algorithms—including Random Forest, Extra Trees, Gradient Boosting, and Ridge—evaluating performance with MAE, RMSE, R², and MAPE to select the optimal predictor. Powered by a responsive Flask web interface for instant valuations in Indian Rupees (INR), vehicle data exploration, and model comparison insights.

Key Features:
  • Supervised ML regression pipeline predicting continuous vehicle resale value from multi-feature historical data.
  • Comprehensive model benchmarking comparing 11 regression algorithms (Random Forest, Gradient Boosting, Extra Trees, SVR, KNN, etc.).
  • Regression evaluation framework tracking MAE, RMSE, R² Score, and MAPE with automated best-model selection.
  • Robust data preprocessing integrating SimpleImputer, One-Hot Encoding, and StandardScaler pipelines.
  • Interactive Flask web application for real-time price prediction and user input validation.
  • Exploratory analytics dashboard with vehicle dataset filtering by brand, fuel type, and transmission.
  • Production-ready model serialization with Joblib for efficient inference without retraining.
Technologies & Algorithms:
Python Flask Scikit-learn Regression Models Pandas NumPy Joblib Data Cleaning HTML5 CSS3 JavaScript
