01 ONLINE TOY STORE & E-COMMERCE
WEB APPLICATION / E-COMMERCE

E-Commerce System for Toy Store

The E-Commerce System for Toy Store is an online shopping platform developed to make buying toys easier and more convenient. Users can explore different toy products, view product details, add items to their shopping cart, and place orders online. The system also provides user authentication, payment handling, and order management features.

Key Features:
  • Online toy product catalog.
  • Product details and categories.
  • Shopping cart functionality.
  • User registration and login.
  • Order management system.
  • Payment handling features.
  • Responsive and user-friendly design.
Technologies Used:
PHP Laravel MySQL HTML CSS JavaScript
02 STUDENT GUIDANCE PLATFORM
WEB APPLICATION / CAREER GUIDANCE

Career Guidance Portal

The Career Guidance Portal is a web-based application designed to help students choose the right career path based on their interests and goals. It provides information about different career opportunities, courses, and educational details. The system also includes user management features and an easy-to-use interface to help students make better career decisions.

Key Features:
  • Career information and guidance.
  • Course and educational details.
  • User management system.
  • Responsive and user-friendly interface.
  • Easy navigation and information access.
Technologies Used:
PHP Laravel MySQL HTML CSS JavaScript
